# Active Practice

Put new work here. Use folders such as `2026-10/week-01/` so attempts stay separate from imported answers.

Name files with the problem slug:

```text
practice/2026-10/week-01/minimum-window-substring.py
```

Start each solution with:

```python
"""Problem name or URL.

Pattern:
Difficulty: Medium / Medium-hard / Hard
Approach:
Time:
Space:
Miss or lesson:
"""
```

Keep failed approaches when they teach something. Put the working solution below them or in a second file named `<slug>_retry.py`.
